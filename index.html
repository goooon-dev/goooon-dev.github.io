mofu channel analytics

運営: mofu (goooon)

このアプリについて

mofu channel analytics は、運営者が自分で運営している YouTube チャンネルの数値（再生回数、高評価数、視聴維持率など）を確認し、動画制作の改善に使うための個人用ツールです。

YouTube Data API と YouTube Analytics API を読み取り専用で利用します。動画のアップロード、編集、削除、コメントの投稿などの書き込みは一切行いません。

運営者本人のチャンネル以外での利用は想定していません。一般公開されているサービスではありません。

About

mofu channel analytics is a personal tool used by its operator to review metrics (views, likes, audience retention) of the YouTube channel the operator owns, in order to improve video production. It uses the YouTube Data API and YouTube Analytics API with read-only scopes and never uploads, edits, deletes, or posts anything. It is not offered as a public service.
